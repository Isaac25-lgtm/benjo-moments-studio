# Benjo Moments Studio

Benjo Moments is a Flask and PostgreSQL application for running a photography
portfolio website and a small studio back office.

## Features

- Public portfolio, album gallery, services, pricing, about, and contact pages
- Editable hero images, gallery images, pricing packages, and website settings
- Customer, invoice, income, expense, asset, and inquiry management
- Atomic invoice settlement that updates customer balances and income
- PostgreSQL constraints, Alembic migrations, CSRF protection, rate limits,
  secure sessions, audit logs, and validated image uploads
- Render deployment with one Gunicorn process, threaded concurrency, hosted
  PostgreSQL, and a persistent upload disk

## Requirements

- Python 3.12
- PostgreSQL 16 or newer

## Local Development

1. Create a PostgreSQL database named `benjo_moments`.
2. Copy `.env.example` to `.env` and set `DATABASE_URL`, `SECRET_KEY`, and the
   initial admin credentials.
3. Install dependencies and apply migrations:

```powershell
python -m pip install -r requirements.txt
python -m alembic upgrade head
python app.py
```

Open:

- Website: `http://127.0.0.1:5000`
- Manager login: `http://127.0.0.1:5000/login`
- Health check: `http://127.0.0.1:5000/healthz`

PostgreSQL is mandatory. The application does not fall back to SQLite.

## Render Deployment

The included `render.yaml` configures:

- `python -m alembic upgrade head` before each deployment
- A paid Starter service in Virginia with exactly one instance
- One Gunicorn worker with four threads
- A five-connection PostgreSQL pool with limited overflow
- A persistent disk at `/opt/render/project/data`
- Database and upload-disk checks at `/healthz`

Set these values in Render:

- `DATABASE_URL`: hosted PostgreSQL connection URL; use a database in the same
  region when possible and include `sslmode=require` for public connections
- `DEFAULT_ADMIN_EMAIL`
- `DEFAULT_ADMIN_PASSWORD`

`SECRET_KEY` is generated by Render. Keep `TEST_AUTH_MODE=false`.
The Starter plan is required because Render Free services do not support
persistent disks.
